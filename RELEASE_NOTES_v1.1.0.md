# v1.1.0 - Animated preview and presentation update

This release expands the original point cloud blob project with a more polished presentation and a lightweight animation workflow.

- Animation support in the `bpy` generation script
- Browser-based preview in `docs/` for GitHub Pages
- Portfolio-ready project descriptions in Russian and English
- Updated README and GitHub setup notes
- GitHub Actions workflow for automatic Pages deployment

- Blender scene (`.blend`)

- Still preview render
