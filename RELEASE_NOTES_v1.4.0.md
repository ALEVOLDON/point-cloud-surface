# v1.4.0 - Mobile-Responsive Layout

## Added

- **Mobile layout** for `docs/interactive.html`
  - On screens narrower than 640 px the control panel is hidden by default — the blob fills the full screen
  - A floating **⚙** button (bottom right) opens the panel as a smooth **bottom sheet** (slides up from the bottom, 60 % of viewport height)
  - Tapping the blob or pressing **✕** closes the panel
  - The audio strip automatically moves up when the panel is open so they never overlap

- **Compact audio strip** on mobile
  - Narrower padding, smaller buttons, no visualiser bars — optimised for small screens

- **Panel scroll** on desktop — the control panel is now scrollable when the viewport is too short to show all controls at once
